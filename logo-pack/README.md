# Runs MyId — Logo Pack
Konsep: perisai (keamanan/identitas) + figur "r" (orang) + tombol play (Runs). Palet hijau-teal.
Warna: #2DD4BF → #047857 (latar), #0F766E (figur), #14B8A6 (play), putih (perisai).

- svg/      master & varian (master, square, round, transparent, adaptive fg/bg, monochrome, wordmark)
- web/      favicon.ico, favicon.svg, PNG 16–512, apple-touch-icon, icon PWA 192/512
- android/  mipmap-*dpi (launcher, round, adaptive fg/bg/monochrome), mipmap-anydpi-v26/ic_launcher.xml, Play Store 512
- ios/      AppIcon.appiconset (Contents.json + semua ukuran, tanpa alpha) + 1024
- store/    App Store 1024, Google Play 512, YouTube profil 800 (bulat), banner 2560x1440, wordmark light/dark

Catatan: teks wordmark SVG memakai font sistem (DejaVu Sans/Arial). Untuk produksi, ubah ke outline di Figma/Inkscape.
